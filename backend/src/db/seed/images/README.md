# Seed images

The photos the seed crops its post images from (see `../images.ts`). Every one is released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) on Wikimedia Commons; the author is
named as a courtesy, CC0 does not require it. Downscaled to 1024 px on the long side, metadata
stripped.

A new photo needs nothing but a `.jpg` in this folder — the seed picks it up — and a line here.
